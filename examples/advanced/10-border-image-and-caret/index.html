Border Image & Caret Color

border-image

border-image: <source> <slice> / <width> <repeat>

Every demo uses a CSS gradient as the image source — no image files needed. The frame has a transparent border that the image replaces.

none

none — no border image (default)

round

gradient 30 round — image sliced at 30px, tiles to fit

stretch

gradient 30 stretch — image stretched to fill

fill

gradient 30 fill — image also fills the middle area

source

border-image-source: linear-gradient(…) — gradient as the source

slice

border-image-slice: 30 — inset distance to slice the image

slice

border-image-slice: 10 20 30 40 — per-edge slice offsets

width

border-image-width: 10px — border image width

outset

border-image-outset: 10px — extends beyond the border box

repeat

border-image-repeat: repeat — tiles without resizing

round

border-image-repeat: round — tiles scaled to fit evenly

space

border-image-repeat: space — tiles with space between

Global keywords also apply: inherit · initial (none) · revert · unset.

caret-color

caret-color: <color> | auto

Click into each field and type to see the caret color.

auto — browser picks a color for contrast (default)

red — any CSS color

#d946ef — hex color

currentColor — matches the text color

transparent — hides the caret

Global keywords also apply: inherit · initial (auto) · revert · unset.
