container-type: inline-size · font-size: 4cqi

The two cards below sit in containers of different widths. Their font sizes scale with the container, not the viewport — resize the window.

Wide card

font-size: 4cqi on the title scales with this card's width.

container ~600px → title uses cqi of its own container

Narrow card

narrower container → smaller cqi-scaled text

cqmin / cqmax — Shape-Safe Scaling

width: 30cqmin · height: 30cqmin

A square sized with cqmin fits inside its container no matter the shape — it tracks the smaller container axis.

30cqmin

width & height: 30cqmin — fits any container shape

ic — Ideographic Character

max-width: 16ic

The CJK paragraph is capped at 16 full-width characters per line using ic.

これはアイデオグラフ文字幅のデモです。十六文字で折り返します。

max-width: 16ic — 16 full-width characters per line

cap — Cap Height

border-bottom: 0.15cap solid

The underline thickness is a fraction of the capital-letter height, so it stays proportional as the font size changes.

CAP

border-bottom: 0.15cap — proportional to uppercase height

Fallback with clamp()

font-size: clamp(1rem, 4cqi, 2rem)

In browsers without container query unit support, the value falls back to the nearest supported clamp baseline.

Clamped

clamp(1rem, 4cqi, 2rem) — safe minimum and maximum.
