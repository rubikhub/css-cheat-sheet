View Transitions

::view-transition

::view-transition { position: fixed; inset: 0; }

The root pseudo-element wraps every snapshot in a fixed, full-viewport layer. Tick the checkbox to overlay the "page".

page
::view-transition

::view-transition — the root transition container

These pseudo-elements exist only while a transition runs — started by startViewTransition() or enabled navigation. The checkboxes simulate that moment; inspect a real transition in DevTools to see the pseudo-elements.

::view-transition-group()

::view-transition-group(<name>) { animation-duration: 0.5s; }

Each named element becomes a transition group. Tick "Run" — the hero group animates slowly (0.5s) while the page group animates faster (0.3s).

::view-transition-image-pair()

::view-transition-image-pair(<name>) { mix-blend-mode: normal; }

The image pair layers the old and new snapshot of a group. Tick "Run" — the old snapshot fades out while the new one fades in on top.

@view-transition

@view-transition { navigation: auto; }

The at-rule opts navigations into view transitions. Tick each checkbox to simulate its navigation scope.

Requires the View Transition API. Until a transition is running — via startViewTransition() or same-origin navigation — the at-rule has no visible effect, so the demos simulate it with checkboxes.
