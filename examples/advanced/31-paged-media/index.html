Paged Media & Print

@page

@page { <descriptors> }

@page rules apply only when printing. This example ships real @page rules in style.css — press the button or Ctrl+P to see them in the print output.

@page {
  margin: 1in;
}

margin: 1in — set printed margins

@page {
  size: A4;
}

size: A4 — set the paper size

@page :first {
  margin-top: 2in;
}

:first — style the first page

@page :left / :right

:left / :right — style left / right pages

size

@page { size: auto | <length> | <page-size> || portrait | landscape }

size: auto

auto — browser default size (default)

size: A4

A4 — ISO A4 paper

size: A4 landscape

A4 landscape — landscape orientation

size: 8.5in 11in

8.5in 11in — explicit dimensions

Global keywords also apply: inherit · initial (auto) · revert · unset.

break-before / break-after

break-before: auto | page | left | right | column

This section carries break-before: page — check the printout to see it start on a fresh page.

break-before: auto

auto — no forced break (default)

break-before: page

page — start on a new page

break-before: left | right

left / right — start on a left / right page

break-before: column

column — start on a new column

Global keywords also apply: inherit · initial (auto) · revert · unset.

break-inside

break-inside: auto | avoid | avoid-page | avoid-column

Every section in this example prints with break-inside: avoid, so each one stays whole on a page.

break-inside: auto

auto — allow breaks (default)

break-inside: avoid

avoid — keep the element whole

break-inside: avoid-page

avoid-page — avoid page breaks inside

break-inside: avoid-column

avoid-column — avoid column breaks inside

Global keywords also apply: inherit · initial (auto) · revert · unset.

orphans / widows

orphans: <integer> | widows: <integer>

orphans: 3

orphans: 3 — at least 3 lines at the bottom of a page

widows: 3

widows: 3 — at least 3 lines at the top of a page

orphans: 1
widows: 1

orphans: 1 / widows: 1 — default

A long paragraph that uses orphans: 3 and widows: 3 — when it breaks across pages, no page may leave fewer than three lines stranded at the bottom or top of a page.

print-color-adjust

print-color-adjust: economy | exact

economy

economy — browser may drop backgrounds to save ink (default)

exact

exact — always print backgrounds and colors

banner

dark banner with print-color-adjust: exact — keeps its colors on paper

Global keywords also apply: inherit · initial (economy) · revert · unset.

Margin Boxes

@page { @top-center { content: ...; } }

style.css adds a running header (string(book-title)) and page numbers (counter(page) " / " counter(pages)) to the printed output.

@top-left / @top-center / @top-right

top margin boxes

@bottom-left / @bottom-center / @bottom-right

bottom margin boxes

content: string(book-title)

content: string(page-title) — string-set content

counter(page) & counter(pages)

content: counter(page) " / " counter(pages);

counter(page)

counter(page) — the current page number

counter(pages)

counter(pages) — the total number of pages

counter(page, lower-roman)

counter(page, lower-roman) — roman page numbers
