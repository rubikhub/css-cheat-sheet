Scroll Snap & Touch Interaction

scroll-snap-type

scroll-snap-type: none | [x | y | both] [mandatory | proximity]

no snap

none — free scrolling (default)

x mandatory

x mandatory — always snaps on the x axis

y mandatory

y mandatory — always snaps on the y axis

x proximity

x proximity — snaps only when close

y proximity

y proximity — snaps on y when close

both mandatory

both mandatory — snaps on both axes

both proximity

both proximity — snaps on both axes when close

Global keywords also apply: inherit · initial (none) · revert · unset.

Drag the strips horizontally (or use shift+scroll) to feel the snapping.

scroll-snap-align

scroll-snap-align: none | start | end | center

align none

none — no alignment (default)

align start

start — aligns item start edge to container

align end

end — aligns item end edge to container

align center

center — centers the item

Global keywords also apply: inherit · initial (none) · revert · unset.

overscroll-behavior

overscroll-behavior: auto | contain | none

auto — chains to parent

auto — default overscroll chaining

contain

contain — prevents chaining to parent

none

none — prevents all overscroll

Global keywords also apply: inherit · initial (auto) · revert · unset.

touch-action

touch-action: auto | none | pan-x | pan-y | pinch-zoom | manipulation

auto

auto — browser decides (default)

none

none — no touch gestures

pan-x

pan-x — horizontal panning only

pan-y

pan-y — vertical panning only

pan-x pan-y

pan-x pan-y — panning both directions

pinch-zoom

pinch-zoom — allows pinch zooming

manipulation

manipulation — pan + pinch, no double-tap zoom

Global keywords also apply: inherit · initial (auto) · revert · unset.
