:has() (Deep)

:has(<relative-selector-list>)

has password input

form:has(input[type="password"]) — blue border

label focused

label:has(+ input:focus) — label colors blue when input is focused

Image, no video

article:has(img):not(:has(video)) — shows image grid

Global keywords also apply: inherit · initial · revert · unset.

:is(h1, h2, h3) — matches any heading (specificity 0,1,0)

Inside .card

paragraph

:is(.card) h4 — matches h4 inside .card

:blank

:blank

input:blank — border turns gray while empty (unlike :empty)

textarea:blank — gray border until text is typed

:blank applies to form controls, distinct from :empty which matches elements.
