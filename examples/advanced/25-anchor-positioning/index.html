Anchor Positioning

anchor-name

anchor-name: <dashed-ident> | none

The dark box is the anchor; the teal box is the popup. The anchor must carry the dashed-ident the popup references.

A
--box

--box — the anchor's dashed-ident name

A
--box?

none — no name; the popup can't attach

Global keywords also apply: inherit · initial (none) · revert · unset.

position-anchor

position-anchor: <anchor-name> | auto

A
--box

--box — links the popup to that anchor

A
auto

auto — default anchor resolution (no link)

Global keywords also apply: inherit · initial (auto) · revert · unset.

anchor()

anchor(<anchor-name>, <side>)

Each popup pins one side of the anchor using the anchor() function inside its insets.

A
bottom

anchor(bottom) — below the anchor

A
top

anchor(top) — above the anchor

A
right

anchor(right) — right side

A
left

anchor(left) — left side

A
center

anchor(center) — centered on the anchor

A
--box bottom

anchor(--box bottom) — named anchor, specific side

anchor-size()

anchor-size(<anchor-name> <dimension>)

A
width
height

anchor-size(--box width) — popup matches the anchor's width; height matches too

position-area

position-area: <area>

Grid-style placement: pick a block edge (top/bottom) and an inline side (left/right/center).

A
top

top — above the anchor

A
bottom

bottom — below the anchor

A
left

left — to the left

A
right

right — to the right

A
top left

top left — top-left corner

A
bottom center

bottom center — bottom, centered

A
auto

auto — no fixed area (default)

Global keywords also apply: inherit · initial (auto) · revert · unset.

position-try-fallbacks

position-try-fallbacks: <try-option>

The popup sits at position-area: bottom, right, or top right. When it would overflow the stage it flips to the opposite edge.

A
flip-block

flip-block — flips across the block axis when overflowing

A
flip-inline

flip-inline — flips across the inline axis

A
both

flip-block flip-inline — flips on both axes

A
none

none — no fallbacks (default); the popup clips

Global keywords also apply: inherit · initial (none) · revert · unset.

@position-try

@position-try --name { position-area: top; }

A reusable named option: the popup starts at bottom and falls back to the --flip-top rule when it would overflow.

A
bottom

position-try-fallbacks: --flip-top — falls back to a named rule

position-visibility

position-visibility: always | anchors-visible | no-overflow

These control whether the popup shows based on the anchor's visibility or its own overflow. In this calm layout all three look identical; they matter when the anchor scrolls out of view.

A
always

always — shown even without an anchor

A
anchors-visible

anchors-visible — hidden when the anchor is off-screen (default)

A
no-overflow

no-overflow — only when it fits without overflowing
