Advanced Visual Effects

backdrop-filter

backdrop-filter: <filter-function-list> | none

Each glass panel sits over the same striped gradient — compare how it filters the pixels behind it.

none

none — no backdrop filter (default)

blur(10px)

blur(10px) — gaussian blur on the backdrop

brightness(150%)

brightness(150%) — adjusts backdrop brightness

contrast(200%)

contrast(200%) — adjusts backdrop contrast

grayscale(100%)

grayscale(100%) — converts backdrop to grayscale

blur+bright

blur(5px) brightness(150%) — combines multiple filters

Global keywords also apply: inherit · initial (none) · revert · unset.

mix-blend-mode

mix-blend-mode: normal | multiply | screen | overlay | darken | lighten | color-dodge | color-burn | hard-light | soft-light | difference | exclusion | hue | saturation | color | luminosity

Every chip is the same orange — only the blend mode differs as it mixes with the photo-like gradient behind it.

normal — no blending (default)

multiply — multiplies colors, darkens

screen — inverts multiply, lightens

overlay — combines multiply and screen

darken — keeps the darker color

lighten — keeps the lighter color

color-dodge — brightens the backdrop

color-burn — darkens the backdrop

hard-light — strong contrast blend

soft-light — subtle contrast blend

difference — subtracts colors

exclusion — like difference, softer

hue — element hue with backdrop saturation/luminosity

saturation — uses element saturation

color — uses element hue and saturation

luminosity — uses element luminosity

Global keywords also apply: inherit · initial (normal) · revert · unset.

isolation

isolation: auto | isolate

Both discs use mix-blend-mode: multiply. The group on the right isolates blending so the discs stop bleeding into the gradient.

auto — no stacking context; discs blend with the gradient (default)

isolate — stacking context scopes blending to the group

Global keywords also apply: inherit · initial (auto) · revert · unset.
