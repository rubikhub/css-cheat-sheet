Container Queries

container-type

container-type: inline-size | size | block-size | normal

inline-size

inline-size — responds to container width (most common)

size

size — containment on both dimensions

block-size

block-size — block size containment only

normal

normal — no containment (default)

Global keywords also apply: inherit · initial (normal) · revert · unset.

Drag the resize handle on the container wrappers to watch the card adapt.

container-name

container-name: <name> | none

sidebar

sidebar — named container, targeted with @container sidebar (...)

card

card — named container for card queries

Global keywords also apply: inherit · initial (none) · revert · unset.

@container

@container (<condition>) { ... } | @container <name> (<condition>) { ... }

min-width query

@container (min-width: 220px) — card switches to a grid layout

named query

@container sidebar (max-width: 260px) — targets a named container

style query

@container style(--theme: dark) — responds to a custom property

Container Query Units

cqw | cqh | cqi | cqb | cqmin | cqmax

cqi title

cqi — title font-size scales with container inline size

cqw

cqw — 1% of container width

cqmin

cqmin — smaller of cqi and cqb

cqh · cqb · cqmax behave identically for their respective axes.
