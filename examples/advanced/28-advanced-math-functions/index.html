Advanced Math Functions

calc()

calc(<expression>)

calc(100% - 2rem)

calc(100% - 2rem) → 328px (360px box − 2rem)

100% / 3

calc(100% / 3) → 120px

1rem + 0.5vw

calc(1rem + 0.5vw) → 16px + 0.5vw

nested

calc(calc(10px * 2) + calc(1rem / 2)) → 28px

clamp()

clamp(<min>, <preferred>, <max>)

clamp(300px, 80%, 1200px)

clamp(300px, 80%, 1200px) → 300px (80% = 288px, clamped up to the min)

fluid

clamp(1rem, 2vw + 0.5rem, 2.5rem) — responsive font-size

pad

clamp(0.5rem, 2vw, 2rem) — fluid padding

min() / max()

min(<values…>) · max(<values…>)

min(100%, 600px)

min(100%, 600px) → 360px (never wider than 600px)

max(300px, 50%)

max(300px, 50%) → 300px (50% = 180px, so the minimum wins)

min(2rem, 5vw)

min(2rem, 5vw) → 32px while 5vw ≥ 32px

max(1rem, 2vw)

max(1rem, 2vw) → 20px at a 1000px viewport

sin() / cos() / tan()

sin(<angle>) · cos(<angle>) · tan(<angle>)

sin

tan

combo
