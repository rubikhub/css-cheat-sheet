CSS At-Rules — Advanced

@property

@property --name { syntax; inherits; initial-value; }

--my-color swatch

syntax: '<color>' with initial-value: #333

--my-size text

syntax: '<length>' with initial-value: 1rem, inherits: true

--my-number value

syntax: '<number>' — typed custom property

animate me

Registered props can be animated

@layer

Cascade order

@layer base, components, utilities — later layers win at equal specificity

The chip shows that utilities beat components and base regardless of source order.
