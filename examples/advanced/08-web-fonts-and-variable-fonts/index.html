Web & Variable Fonts

@font-face

@font-face { font-family: <name>; src: url(...) format(...); font-weight: ...; font-style: ...; font-display: ...; }

No network fonts are used on this page — the demo family maps to a locally installed font, so the @font-face structure applies while the page still works offline.

@font-face {
  font-family: "DemoFont";
  src: local("Segoe UI");
  font-weight: 100 900;
  font-style: normal;
  font-display: swap;
}

font-family: "DemoFont"

font-family — the name used to reference the font

src: local("Segoe UI")

src — font file (or local font) and format

font-weight: 100 900

font-weight — range of supported weights

font-style: normal

font-style — style of the loaded face

font-display: swap

font-display — fallback behavior while loading

Bold & italic DemoFont

rendered via the @font-face above — falls back to local Segoe UI

@font-feature-values

@font-feature-values <family> { @styleset { ... } }

Named feature values are bound to one family and referenced with font-variant-alternates. They only take effect when that family actually ships the feature.

@font-feature-values DemoFont {
  @styleset { pretty: "ss01"; }
  @swash    { swsh: 1; }
}

@font-feature-values DemoFont

binds the named values to a font family

@styleset { pretty: "ss01" }

@styleset — named stylistic set values

@swash { swsh: 1 }

@swash — named swash values

Styled with pretty

font-variant-alternates: styleset(pretty) — uses the named value

font-variation-settings

font-variation-settings: <axis> <value>

Uses the variable family “Segoe UI Variable” when installed (Windows 10/11), otherwise falls back to system-ui. Axes only change the rendering when the font supports them.

Weights 200

'wght' 200 — set the weight axis

Weights 700

'wght' 700 — heavier weight

Expanded width

'wdth' 110 — set the width axis

Optical 36

'opsz' 36 — set the optical size axis

Multi-axis

'wght' 750, 'opsz' 36, 'wdth' 110 — multiple axes at once

Custom axis

'XTRA' 500 — set a custom axis

Normal

normal — no variation (default)

Global keywords also apply: inherit · initial (normal) · revert · unset.

font-optical-sizing

font-optical-sizing: auto | none

Optical sizing switches to a size-specific design when the font provides one — Segoe UI Variable adjusts its optical size as the text grows.

Aa

auto — browser adjusts optical size (default)

Aa

none — disables optical sizing

Global keywords also apply: inherit · initial (auto) · revert · unset.
