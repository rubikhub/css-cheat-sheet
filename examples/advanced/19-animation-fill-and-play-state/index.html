Animation — Direction, Fill Mode & Play State

animation-direction

animation-direction: normal | reverse | alternate | alternate-reverse

Each disc slides on a 2s loop in its own direction. Uncheck a box to pause it mid-travel.

normal

normal — plays forward (default)

reverse

reverse — plays backward

alternate

alternate — forward then backward

alt-rev

alternate-reverse — backward then forward

Global keywords also apply: inherit · initial (normal) · revert · unset.

animation-fill-mode

animation-fill-mode: none | forwards | backwards | both

Tick a box to play a one-shot slide (1s, 0.6s delay). Compare how each mode holds the start frame during the delay and the end frame after.

none

none — no styles before/after (default)

forwards

forwards — retains the final keyframe values

backwards

backwards — applies the first keyframe during the delay

both

both — applies forwards and backwards

Global keywords also apply: inherit · initial (none) · revert · unset.

animation-play-state

animation-play-state: running | paused

Pause or resume each disc with its checkbox — pausing freezes it mid-turn.

running — plays normally (default)

paused — frozen (check to run)

Global keywords also apply: inherit · initial (running) · revert · unset.
