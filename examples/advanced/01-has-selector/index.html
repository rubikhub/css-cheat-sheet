:has() — The Parent Selector

:has()

:has(<relative-selector-list>)

Card with an image

.card:has(img) — card turns blue grid when it contains an image

filled with a valid email → no red

form:has(:invalid) — red border while input is invalid

label:has(+ input:checked) — highlight the label of a checked input

Image

div:has(p):has(img) — only when both p and img are inside

Card with no image

.card:not(:has(img)) — cards without an image stay muted

  • Item 1

.list:has(> :empty) — outline when a direct child is empty

Global keywords also apply: inherit · initial · revert · unset.
