CSS Masks

mask-image

mask-image: <image> | none

Each box is revealed only where the mask is opaque — bright parts show the colorful stripes.

none — no mask (default)

url('mask.svg') — star mask via inline SVG data URI

linear-gradient(black 40%, transparent) — top stays, bottom fades

radial-gradient(circle, black 30%, transparent 70%) — soft disc

Global keywords also apply: inherit · initial (none) · revert · unset.

mask-mode

mask-mode: match-source | alpha | luminance

The same idea interpreted three ways — alpha reads transparency, luminance reads brightness.

match-source — alpha for CSS images, luminance for SVG (default)

alpha — masks by the alpha channel (soft-edged disc)

luminance — masks by brightness (white→black fade)

Global keywords also apply: inherit · initial (match-source) · revert · unset.

mask-composite

mask-composite: add | subtract | intersect | exclude

A circle on the left and a square on the right overlap; the composite operator decides what stays visible.

add — layers overlaid (default)

subtract — later layers cut out

intersect — keeps the overlapping area

exclude — keeps non-overlapping areas

Global keywords also apply: inherit · initial (add) · revert · unset.

mask-size

mask-size: <length> | <percentage> | auto | cover | contain

One circle mask, five sizes — compare how cover clips edges while contain fits the whole circle.

auto — natural mask size (100×100)

cover — scales to cover the element (edges clipped)

contain — scales to fit entirely

50% 50% — percentage sizing (65×50)

100px 200px — length sizing (stretched)

Global keywords also apply: inherit · initial (auto) · revert · unset.

mask-position

mask-position: <position>

A 40px mask circle moves around the 130×100 box.

center — centered

top left — pinned to the corner

50% 50% — percentage position (equal to center here)

10px 20px — offset from the top-left corner

Global keywords also apply: inherit · initial (0% 0%) · revert · unset.
