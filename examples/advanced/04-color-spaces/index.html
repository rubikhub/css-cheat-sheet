Color Spaces

oklch()

oklch(L C H / alpha)

Checkerboard marks transparency — the / 0.8 swatch is 80% opaque.

oklch(70% 0.15 250) — blue at 70% lightness

oklch(0.9 0.05 100 / 0.8) — pale green at 80% opacity

oklch(0.5 0.2 300) — purple at 50% lightness

oklch(65% 0.15 260) — primary blue

oklch(75% 0.2 30) — orange accent

Global keywords also apply: inherit · initial · revert · unset.

oklab()

oklab(L a b / alpha)

Fine-tune with the a axis (green↔red) and b axis (blue↔yellow).

oklab(0.7 0.1 -0.1) — mid lightness, green-blue cast

oklab(0.9 0.05 0.05 / 0.5) — pale color at 50% opacity

oklab(0.5 0.2 0) — deep neutral color

Global keywords also apply: inherit · initial · revert · unset.

lch()

lch(L C H / alpha)

CIE LCH — keep perceptual lightness stable while changing hue.

lch(70% 50 240) — blue at 70% lightness

lch(90% 30 120 / 0.9) — green at 90% opacity

lch(50% 60 20) — saturated red-orange

Global keywords also apply: inherit · initial · revert · unset.

lab()

lab(L a b / alpha)

Device-independent — colors match across displays.

lab(50% 30 -20) — green-blue at 50% lightness

lab(90% 10 20 / 0.8) — pale red at 80% opacity

lab(30% 50 50) — deep red

Global keywords also apply: inherit · initial · revert · unset.

color()

color(<color-space> <channels> / <alpha>)

Wide-gamut spaces — each swatch ships an sRGB fallback first, so it still renders on narrower displays.

color(display-p3 1 0.5 0) — orange in Display P3

color(prophoto-rgb 0.8 0.4 0.2) — brown in ProPhoto RGB

color(rec2020 0.5 0.3 0.7) — purple in Rec2020

Global keywords also apply: inherit · initial · revert · unset.

hwb()

hwb(H W B / alpha)

Add whiteness or blackness directly to a hue to build tints and shades.

hwb(120 0% 0%) — pure green

hwb(30 40% 10%) — soft orange

hwb(240 100% 0%) — white

hwb(0 0% 100%) — black

hwb(210 20% 10%) — example steel blue

Global keywords also apply: inherit · initial · revert · unset.

device-cmyk()

device-cmyk(<c> <m> <y> <k> / <alpha>)

Print-targeted ink definitions — browsers approximate to sRGB, so each swatch has an sRGB fallback.

device-cmyk(0 1 1 0) — red in CMYK

device-cmyk(1 0 0 0) — cyan in CMYK

device-cmyk(0 0 0 1) — black in CMYK

device-cmyk(0.2 0.6 0.1 0.3) — example brown

Global keywords also apply: inherit · initial · revert · unset.
