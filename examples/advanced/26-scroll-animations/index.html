animation-range

animation-range: <start> <end>

Six items share a view() timeline but slice it differently. Scroll slowly to watch each one's range.

0% 100%
entry 0% entry 100%
exit 0% exit 100%
cover 0% cover 100%
contain 0% contain 100%
normal

0% 100% / cover — animate across the whole visibility · entry — only while entering · exit — only while leaving · contain — only while fully inside · normal — the default (cover)

Global keywords also apply: inherit · initial (normal) · revert · unset.

animation-range-name

animation-range-name: <custom-ident> | normal

A named range point can be reused in animation-range-start / animation-range-end for fine control.

--my-range
normal

--my-range — a named point, referenced elsewhere · normal — default range name

Global keywords also apply: inherit · initial (normal) · revert · unset.

animation-range-start / animation-range-end

animation-range-start: <start> · animation-range-end: <end>

One card starts late (20% through entry), the other ends early (80% through exit).

start: entry 20%
end: exit 80%

entry 20% — the fade-in begins later · exit 80% — the fade-out ends earlier

Global keywords also apply: inherit · initial (normal) · revert · unset.

view-timeline

view-timeline-name: <name> · view-timeline-axis: <axis>

The purple subject declares a named view timeline; its amber child bar is animated by that timeline and fills as the subject crosses the box.

subject

view-timeline-name: --reveal · view-timeline-axis: block — the bar tracks the subject's progress

Global keywords also apply: inherit · initial (none block) · revert · unset.

timeline-scope

timeline-scope: <name> | none

timeline-scope: --scroller lets the green bar outside the box see the box's scroll timeline. Without it (none) the bar stays empty.

--my-timeline — the box's timeline is exposed to the bar below

none — no scoping; the bar never fills

Global keywords also apply: inherit · initial (none) · revert · unset.
