Motion Path

offset-path

offset-path: none | <basic-shape> | path(<string>)

Each track's red dot rides its path forever.

none — no motion path (default)

path('M 10 90 C 35 15 95 15 120 90') — SVG curve

circle(50px at 50% 50%) — circular path

polygon(0 0, 100% 0, 100% 100%) — triangular path

ray(135deg) — a straight diagonal ray

offset-distance

offset-distance: <length-percentage>

Three dots pinned to the same straight path at different distances.

0% — at the start of the path

100% — at the end of the path

40px — a fixed distance along the path

offset-rotate

offset-rotate: auto | reverse | <angle>

Arrows follow the same S-curve; watch how each one's orientation differs.

auto — follows the path direction (default)

reverse — faces opposite the path direction

0deg — keeps a fixed orientation

auto 45deg — path direction plus 45deg

offset-anchor

offset-anchor: auto | <position>

Same circle path, different points of the dot aligned to the path — center, top-left corner, and bottom-center.

auto — the center rides the path (default)

top left — the top-left corner rides the path

50% 100% — the bottom-center rides the path

offset

offset: <position> || <path> || <distance> || <rotate> || <anchor>

offset: path('M 10 90 L 120 10') 50% — path with distance

offset: circle(40px at 50% 50%) 0deg — path with rotation

offset: auto — resets all offset properties
