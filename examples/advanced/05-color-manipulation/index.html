relative color syntax

oklch(from <color> <components>)

Every swatch derives from --primary: #667eea with oklch(from …). Hover the button for a live darker variant.

base — var(--primary)

oklch(from var(--primary) calc(l + 0.2) c h) — lighter

oklch(from var(--primary) calc(l - 0.2) c h) — darker

oklch(from var(--primary) l c h / 50%) — transparent

oklch(from var(--primary) l calc(c * 0.5) h) — desaturated

:hover — oklch(from var(--primary) calc(l - 0.1) c h)

Global keywords also apply: inherit · initial · revert · unset.

color-scheme

color-scheme: normal | light | dark | light dark

Each panel declares a scheme — checkboxes and date pickers restyle. `light dark` follows your OS setting.

normal — no preference (default)

light — light scheme only

dark — dark scheme only

light dark — supports both

Global keywords also apply: inherit · initial (normal) · revert · unset.

light-dark()

color: light-dark(<light-color>, <dark-color>)

light-dark(var(--bg), var(--bg-dark))

custom properties — same flip

Tick the checkbox — the stage flips color-scheme and both cards re-resolve light-dark()

Requires color-scheme on an ancestor. The checkbox-hack flips this stage between light and dark without touching the OS.

Global keywords also apply: inherit · initial · revert · unset.

contrast-color()

contrast-color(<color>)

Hover each badge — the background swaps and contrast-color() re-picks black or white text (Baseline 2026).

contrast-color(white)

black text on white — hover flips the background to black

contrast-color(#667eea)

automatic contrast against a brand color

contrast-color(var(--bg))

Global keywords also apply: inherit · initial · revert · unset.
