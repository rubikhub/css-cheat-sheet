font-feature-settings

font-feature-settings: <feature-tag> <value>

Features are switched on by OpenType tag. Each font decides which tags it actually supports — if a tag is missing, the declaration has no visible effect.

Ligature pairs such as “fi”, “fl” and “ffi” are clearest in a serif face.
