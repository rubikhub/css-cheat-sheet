text-indent

First line is indented by two em units. The rest of the paragraph flows normally.

2em — indent by 2em

First line is indented by twenty pixels. The rest of the paragraph flows normally.

20px — fixed pixel indent

First line is indented by ten percent of the container width. The rest flows normally.

10% — percentage of container width

First line indented, and so is every wrapped line. The whole paragraph shifts right.

First line has no indent at all. The paragraph starts flush with the edge.

0 — no indent (default)
