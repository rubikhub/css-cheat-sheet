Basic Selectors

Universal Selector

* { box-sizing: border-box; margin: 0; padding: 0; }

a paragraph

a div
a span

* — every element inside the box is matched

Commonly used with box-sizing, resets, and applying default styles to everything.

Element Selector

p { … }  h1 { … }  div { … }  a { … }  img { … }

p

p — all paragraph elements

h1

h1 — all h1 elements

div

div — all div elements

a

a — all anchor elements

img — all image elements

Class Selector

.class

.button

.button — elements with class="button"

.card

.card — elements with class="card"

.active

.active — elements with class="active"

.primary

.primary — elements with class="primary"

Classes are the workhorse of reusable component styling and variants.

ID Selector

#id

#header

#header — element with id="header"

#main-content

#main-content — element with id="main-content"

#footer

#footer — element with id="footer"

#hero

#hero — element with id="hero"

IDs must be unique on a page — use them for unique sections, not reusable styles.

Attribute Selector

[attribute]  |  [attribute="value"]

[href] link

[href] — elements with an href attribute

[type="text"] — exact attribute match
