Pseudo-Elements Basics

::before

::before { content: ... }

::before inserts generated content before the element's real content.

item

content: "" — empty pseudo-element (custom bullet)

title

content: "★" — icon content

hover

content: attr(data-tooltip) — attribute value

::after

::after { content: ... }

::after inserts generated content after the element's real content.

learn more

content: "→" — arrow icon

visit

content: attr(href) — link URL

hover me

content: "" — empty pseudo-element (animated underline)

::first-line

p::first-line

p::first-line — the first wrapped line of this paragraph is bold and blue, while the rest keeps its normal style.

p::first-line — first line of paragraphs

.article::first-line — articles style their opening line differently to draw the reader in.

.article::first-line — first line of articles

::first-letter

p::first-letter

p::first-letter — the first character is enlarged and colored for emphasis.

p::first-letter — first letter of paragraphs

.drop-cap::first-letter — a classic drop cap floats the big letter into the text.

.drop-cap::first-letter — drop cap styling

::selection

Global ::selection — this paragraph uses the site-wide selection style (blue on white).

::selection — selected text

p::selection — this paragraph overrides selection with its own green style.

p::selection — selected text in paragraphs
