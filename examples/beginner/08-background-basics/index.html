Background Basics

background-color

background-color: <color>

transparent

transparent — no color (default)

red

red — named color

currentColor

currentColor — matches text color

#ff5733

#ff5733 — hex color

#f00

#f00 — short hex

rgb(255, 0, 0)

rgb(255, 0, 0) — RGB color

rgba(255, 0, 0, 0.5)

rgba(255, 0, 0, 0.5) — RGB with alpha

hsl(0, 100%, 50%)

hsl(0, 100%, 50%) — HSL color

hsla(0, 100%, 50%, 0.5)

hsla(0, 100%, 50%, 0.5) — HSL with alpha

Global keywords also apply: inherit · initial (transparent) · revert · unset.

background-image

background-image: none | <image>

none

none — no image (default)

image

url('assets/…jpg') — local image, cover

Global keywords also apply: inherit · initial (none) · revert · unset.

background-repeat

background-repeat: repeat | no-repeat | repeat-x | repeat-y | round | space

repeat

repeat — tile both directions (default)

no-repeat

no-repeat — no tiling

repeat-x

repeat-x — tile horizontally only

repeat-y

repeat-y — tile vertically only

round

round — tile and resize to fit

space

space — tile with even spacing

repeat space

repeat space — horizontal repeat, vertical space

Global keywords also apply: inherit · initial (repeat) · revert · unset.

background-size

background-size: auto | cover | contain | <length> | <percentage>

auto

auto — intrinsic size (default)

cover

cover — scale to fill container

contain

contain — scale to fit inside

200px

200px — fixed width

200px 100px

200px 100px — fixed width and height

50%

50% — percentage of container

50% 75%

50% 75% — width and height percentages

Global keywords also apply: inherit · initial (auto) · revert · unset.

background-position

background-position: <position>

top

top — top edge

bottom

bottom — bottom edge

left

left — left edge

right

right — right edge

center

center — centered (default)

20px

20px — x offset, y centered

50%

50% — x at 50% (centered)

top right

top right — keyword pair

center bottom

center bottom — center horizontal, bottom vertical

right 10px bottom 20px

right 10px bottom 20px — precise positioning

Global keywords also apply: inherit · initial (0% 0%) · revert · unset.

background

background: <bg-image> <position> / <size> <repeat> <attachment> <clip> <origin> <color>

red

red — just color

image

url('assets/…jpg') — just image (tiles by default)

center

center — just position

no-repeat

no-repeat — just repeat

fixed

fixed — image stays fixed while page scrolls

center no-repeat

url('assets/…jpg') center no-repeat — multiple values

full

red url('assets/…jpg') center/cover no-repeat — full shorthand
