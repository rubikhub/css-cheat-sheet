Color Functions Basics

Named Colors

color: <named-color>

Named colors are words the browser already knows. The checkerboard shows transparency.

red — #ff0000

blue — #0000ff

green — #008000

black — #000000

white — #ffffff

transparent — fully transparent

currentColor — matches the current text color

Hex Colors

color: #RRGGBB | #RGB

#ff5733 — 6-digit hex (full)

#f00 — 3-digit hex (shorthand)

#ff573380 — 8-digit hex (with alpha)

#f008 — 4-digit hex (shorthand with alpha)

RGB / RGBA

color: rgb(red, green, blue) | rgba(red, green, blue, alpha)

rgb(255, 0, 0) — pure red

rgb(0, 128, 0) — green

rgb(255, 255, 255) — white

rgba(0, 0, 0, 0.5) — black at 50% opacity

rgb(0% 50% 100%) — percentage values

rgb(255 0 0 / 0.5) — modern space syntax

HSL / HSLA

color: hsl(hue, saturation%, lightness%) | hsla(hue, saturation%, lightness%, alpha)

hsl(0, 100%, 50%) — pure red

hsl(120, 100%, 50%) — pure green

hsl(240, 100%, 50%) — pure blue

hsla(0, 0%, 0%, 0.5) — black with opacity

hsl(200 50% 50%) — modern space syntax

currentColor

color: currentColor

currentColor is a keyword that resolves to the element's computed text color — change the text color once and borders, shadows, and gradients follow.

border

currentColor in border — matches text color

shadow

currentColor in box-shadow

gradient

currentColor in linear-gradient

transparent

background: transparent

hover me

background: transparent — fills in on hover

transparent — rgba(0, 0, 0, 0)

Hover the first box to see the transparent background fill with white.
