CSS Units Basics

px — Pixels (Absolute)

width: 200px · padding: 12px · border: 1px solid

Absolute units are fixed — they do not change with parent size, root font, or viewport.

200px

width: 200px — fixed on every screen

1px

border: 3px solid — crisp fixed edge

12px

padding: 12px — fixed inset

% — Percentage (Parent-Relative)

width: 80% · width: 50%

The gray frame is the parent. Each blue child is a percentage of it.

80%
50%
25%

em — Relative to Parent Font

font-size: 1.5em · padding: 1em

em compounds through nesting — each box multiplies the parent font size.

16px
1.5em = 24px
1.5em = 36px

rem — Relative to Root Font

font-size: 2rem · font-size: 1rem

rem ignores nesting — it always measures against the root (html) font size.

16px root
2rem = 32px
2rem = still 32px

vw / vh — Viewport Units

height: 30vh · width: 60vw

Each strip is a fraction of the visible window. Resize the window to see them change.

60vw wide
30vh tall

Unitless Values

line-height: 1.5 · opacity: 0.8 · flex: 1

line-height: 1.5 — no unit needed, scales with font size.

This paragraph has line-height: 1.5 — the spacing between these lines scales automatically with the font size, with no unit required.
