Transition Basics

transition-property

transition-property: none | all | <property-list>

Hover each box. All of them change background, transform, opacity and color — only the listed properties actually animate.

none

none — no transitions (default), changes snap

all

all — animate every property

opacity

opacity — animate opacity only

transform

transform — animate transform only

bg-color

background-color — animate background only

color, opacity

color, opacity — animate multiple properties

Global keywords also apply: inherit · initial (all) · revert · unset.

transition-duration

transition-duration: <time>

Hover each box and watch how the speed differs.

0s

0s — instant (default)

0.2s

0.2s — fast transition

0.3s

0.3s — standard transition

0.5s

0.5s — slow transition

1s

1s — very slow transition

200ms

200ms — milliseconds

Global keywords also apply: inherit · initial (0s) · revert · unset.

transition-timing-function

transition-timing-function: ease | linear | ease-in | ease-out | ease-in-out | cubic-bezier() | steps()

Hover each box — a slow 0.8s run makes the acceleration curve visible.

ease

ease — slow start and end (default)

linear

linear — constant speed

ease-in

ease-in — starts slow

ease-out

ease-out — ends slow

ease-in-out

ease-in-out — slow start and end

bezier

cubic-bezier(0.4, 0, 0.2, 1) — custom curve

steps

steps(5, end) — stepped animation

Global keywords also apply: inherit · initial (ease) · revert · unset.

transition-delay

transition-delay: <time>

Hover each box — longer delays wait before moving.

0s

0s — start immediately (default)

0.1s

0.1s — small delay

0.2s

0.2s — noticeable delay

100ms

100ms — milliseconds

Global keywords also apply: inherit · initial (0s) · revert · unset.

transition

transition: <property> <duration> <timing-function> <delay>

Hover each box — the shorthand combines property, duration, timing and delay in one declaration.

all 0.3s ease

all 0.3s ease — everything, 0.3s

bg 0.2s

background-color 0.2s ease-in-out

opacity

opacity 0.5s linear 0.1s — with delay

none

none — no transitions (default)

Global keywords also apply: inherit · initial (all 0s ease 0s) · revert · unset.
