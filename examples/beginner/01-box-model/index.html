Box Model

content-box vs border-box

content-box (default)

width: 200px
padding: 20px
border: 10px
Total = 260px

border-box

width: 200px
padding: 20px
border: 10px
Total = 200px

Padding Shorthand

padding: 1rem (all sides)
padding: 1rem 2rem (vertical | horizontal)
padding: 10px 20px 15px 5px (top | right | bottom | left)

Border Shorthand

border: 1px solid #333
border-top: 1px solid red / border-bottom: 2px dashed green

Margin Shorthand

margin: 1rem
margin: 1rem 2rem
margin: 0 auto (centered)

Width Values

width: 200px
width: 50%
width: auto (fills available space)

Overflow

overflow: visible

This text overflows the box and is visible outside its boundaries.

overflow: hidden

This text overflows the box but is clipped and not visible.

overflow: scroll

This text overflows the box and scrollbars are always shown.

overflow: auto

This text overflows the box and scrollbars appear only when needed.
