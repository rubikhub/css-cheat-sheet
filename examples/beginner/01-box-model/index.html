Box Model

The Four Areas

margin-box → border-box → padding-box → content-box

MARGIN — outside the border
BORDER — wraps padding + content
PADDING — space around content
CONTENT

Four concentric boxes: margin wraps border wraps padding wraps content.

box-sizing

box-sizing: content-box | border-box

content-box

content-box — width applies to content only; total = width + padding + border

border-box

border-box — width includes padding and border (recommended)

Global keywords also apply: inherit · initial (content-box) · revert · unset.

Common reset: * { box-sizing: border-box; } — applied globally via the universal selector.

width / height

width: <length> | <percentage> | auto | min-content | max-content | fit-content

200px

200px — fixed width

50%

50% — relative to the container

auto

auto — fills available space (default)

min-content

min-content — smallest possible width

max-content

max-content — largest possible width

fit-content

fit-content — fits content, capped by a percentage

height accepts the same value types as width.

padding

padding: <length>{1,4}

1rem

padding: 1rem — all sides

1rem 2rem

padding: 1rem 2rem — vertical | horizontal

1rem 2rem 1.5rem

padding: 1rem 2rem 1.5rem — top | horizontal | bottom

10px 20px 15px 5px

padding: 10px 20px 15px 5px — top | right | bottom | left

padding-top

padding-top: 1rem — single side

padding-left

padding-left: 2rem — single side

border

border: <width> <style> <color>

1px solid #333

border: 1px solid #333 — shorthand

border-width: 2px

border-width: 2px — line thickness

border-style: solid

border-style: solid — line style

border-color: blue

border-color: blue — line color

border-top: red

border-top: 1px solid red — individual side

border-bottom: dashed green

border-bottom: 2px dashed green — individual side

margin

margin: <length>{1,4} | auto

1rem

margin: 1rem — all sides

1rem 2rem

margin: 1rem 2rem — vertical | horizontal

0 auto

margin: 0 auto — centered horizontally

20px

margin-top: 20px — single side

line
-10px

margin-top: -10px — negative margin pulls elements closer

overflow

overflow: visible | hidden | scroll | auto

overflow: visible — this long text spills out of the box boundary.

visible — content spills out (default)

overflow: hidden — this long text is clipped at the box edge.

hidden — clips the overflowing content

overflow: scroll — scrollbars are always shown.

scroll — always shows scrollbars

overflow: auto — scrollbars appear only when needed.

auto — shows scrollbars only when needed

overflow-x: auto — horizontal scroll only.

overflow-x: auto — horizontal scroll only

overflow-y: auto — vertical scroll only.

overflow-y: auto — vertical scroll only

Global keywords also apply: inherit · initial (visible) · revert · unset.
