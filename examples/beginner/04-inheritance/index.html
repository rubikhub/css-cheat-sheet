Inheritance

How Inheritance Works

html { color: lightslategray; }

parent — color set here

child p — inherits color

nested span — still inherits

Properties cascade down from parent to child; every nested element inherits

Inheritance only flows downward — children inherit from parents, never the other way around.

Which Properties Inherit?

parent: font, color, letter-spacing

child inherits the font and color

Inherited by default: color, fonts, line-height, text-align, cursor, list-style…

parent: border, padding, background

child does NOT inherit border or background

Not inherited: width, height, margin, padding, border, background, display, position…

Controlling Inheritance

inherit | initial | revert | unset | all

parent (weight 400) with strong

font-weight: inherit — strong matches its parent's weight

parent (weight 700) with strong

font-weight: initial — strong resets to the CSS default (400)

styled p has 2rem padding

this p uses padding: revert

padding: revert — drops back to the browser default padding

parent color

golden, 2em margin-top

unset: inherits color, margin resets to 0

color: unset inherits · margin: unset resets (margin does not inherit)

parent color

styled: goldenrod, bold, padded, margined

all: unset — plain, inherits color, no margin or padding

all: unset resets every property at once

Global keywords also apply: inherit · initial · revert · unset. unset behaves like inherit for inherited properties and like initial for the rest.

Practical Example

body { font-family: Arial; font-size: 16px; color: #333; }

This inherits font-family, font-size, and color from its parent.

One declaration on an ancestor styles every descendant

Quick Reference

Keyword Behavior
inherit Use the parent's computed value
initial Use the property's CSS default
revert Undo styles from the same cascade origin
unset inherit if the property inherits, otherwise initial
