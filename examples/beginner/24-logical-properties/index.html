Logical Properties

Physical vs Logical

top / bottom / left / right → block-start / block-end / inline-start / inline-end

Physical directions are absolute; logical ones follow the writing direction, so the same CSS works for LTR and RTL.

Physical Logical Meaning
top block-start before the text block
bottom block-end after the text block
left inline-start where lines start (LTR: left, RTL: right)
right inline-end where lines end (LTR: right, RTL: left)

Writing Modes

direction: ltr | rtl · writing-mode: horizontal-tb | vertical-rl

Left-to-right text flows this way across the page.

direction: ltr — default for English

טקסט בעברית זורם מימין לשמאל.

direction: rtl — Arabic / Hebrew

縦書き日本語のテキストです。

writing-mode: vertical-rl — Japanese

Quick Reference

physical → logical

Category Physical Logical
Margin margin-top margin-block-start
Padding padding-left padding-inline-start
Border border-right border-inline-end
Size width inline-size
Position top inset-block-start
Text text-align: left text-align: start

Why Use Logical Properties?

layout that follows the writing direction

RTL support — layouts automatically adapt to right-to-left languages.
Writing modes — works with vertical text.
Future-proof — more flexible than physical directions.
Less code — no need for separate RTL stylesheets.
