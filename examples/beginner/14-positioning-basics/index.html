Positioning Basics

position

position: static | relative | absolute | fixed | sticky

static

static — default, follows normal flow

relative

relative — shifted from its normal spot

absolute

absolute — relative to nearest positioned ancestor

fixed

fixed — relative to the viewport (bottom-right)

Global keywords also apply: inherit · initial (static) · revert · unset.

top / right / bottom / left

top: <length> | <percentage> | auto

auto

auto — no offset (default), stays at static spot

10px

10px — pixel offset from top-left

2em

2em — em-based offset

50%

50% — percentage of containing block

0

0 — flush with the edge

float

float: none | left | right | inline-start | inline-end

none

The box sits in normal flow and the text below it, so nothing wraps around it.

none — element is not floated (default)

left

The box floats to the left and this paragraph text wraps around it neatly.

left — element floats to the left

right

The box floats to the right and this paragraph text wraps around it neatly.

right — element floats to the right

start

Inline-start means left in LTR, so this text wraps to the right of the box.

inline-start — floats to start of inline direction (left in LTR)

end

Inline-end means right in LTR, so this text wraps to the left of the box.

inline-end — floats to end of inline direction (right in LTR)

Global keywords also apply: inherit · initial (none) · revert · unset.

clear

clear: none | left | right | both | inline-start | inline-end

L
none

Not cleared, so it sits beside the left float.

none — allows floats on both sides (default)

L
left

Cleared left, so it drops below the float.

left — clears left floats

L
right

Only clears right floats, so it stays beside this left float.

right — clears right floats only

L
both

Cleared on both sides, so it drops below the float.

both — clears both left and right floats

L
start

Clears start-side floats (left in LTR), so it drops below.

inline-start — clears start-side floats

L
end

Only clears end-side floats (right in LTR), so it stays beside this left float.

inline-end — clears end-side floats

Global keywords also apply: inherit · initial (none) · revert · unset.
