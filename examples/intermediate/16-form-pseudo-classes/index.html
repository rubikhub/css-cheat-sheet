Form Pseudo Classes

:enabled

input:enabled | button:enabled | select:enabled

All three controls are usable — enabled fields get a green border.

input:enabled — enabled inputs

button:enabled — enabled buttons

select:enabled — enabled selects

:disabled

input:disabled | button:disabled | select:disabled

Disabled controls are greyed out and cannot be focused or used.

input:disabled — disabled inputs

button:disabled — disabled buttons

select:disabled — disabled selects

:checked

input:checked | input:checked + label | input:checked::before

Click the checkboxes — the checked state is styled blue.

input:checked — checked inputs use accent-color

input:checked + label — the adjacent label turns bold blue

input:checked::before — a "✓" marker via ::before

:indeterminate

input:indeterminate | input:indeterminate + label | progress:indeterminate

The checkbox is set to indeterminate via a script; the radio group has no selection; the progress bar has no value.

input:indeterminate — indeterminate checkboxes

input:indeterminate + label — an unchecked radio group is indeterminate

progress:indeterminate — no value attribute

:placeholder-shown

input:placeholder-shown | input:placeholder-shown + label | textarea:placeholder-shown

Type into the fields — the amber placeholder state disappears once there is text.

input:placeholder-shown — empty input showing a placeholder

input:placeholder-shown + label — label next to an empty input

textarea:placeholder-shown — empty textareas

:required

input:required | input:required + label::after | select:required | textarea:required

Required fields get a red left border; their labels gain a red asterisk.

input:required — required inputs

input:required + label::after — asterisk on the label

select:required — required selects

textarea:required — required textareas

:optional

input:optional | input:optional + label | select:optional | textarea:optional

Optional fields get a green left border and are de-emphasized.

input:optional — optional inputs

input:optional + label — label next to an optional input

select:optional — optional selects

textarea:optional — optional textareas

:valid / :invalid

input:valid | input:invalid

Type in the email fields — a valid address is green, an invalid one is red.

input:valid — value meets its constraints

input:invalid — value violates its constraints

:invalid also matches empty required fields before interaction.

:in-range / :out-of-range

input:in-range | input:out-of-range

Both fields allow 1–10 — type 5 (green) or 15 (red).

input:in-range — value within the allowed range

input:out-of-range — value outside the allowed range

:read-only / :read-write

input:read-only | textarea:read-only | [contenteditable]:read-write

Read-only fields are greyed with a dashed border; the editable box keeps a blue outline.

input:read-only — non-editable fields

textarea:read-only — read-only text areas

Click and edit me

[contenteditable]:read-write — editable content

:autofill

input:autofill | input:-webkit-autofill

Browsers only autofill real forms with saved data, so this state cannot be triggered here — the rule would restyle the default yellow fill.

input:autofill — autofilled inputs (also pair -webkit-autofill for Safari)

:default

button:default | input:default

The submit button is the form's default button; the radio with a checked attribute is the default choice.

button:default — the default submit button

input:default — the default-checked radio
