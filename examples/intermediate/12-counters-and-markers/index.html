Counters & Markers

counter-reset

counter-reset: <name> <integer> | none

Each chip shows the value of the counter it creates or resets.

none — no counter reset

myCounter — create counter at 0

myCounter 0 — create counter at 0

myCounter 10 — create counter at 10

myCounter -1 — create counter at -1

/

myCounter 0 anotherCounter 0 — reset multiple

Global keywords also apply: inherit · initial (none) · revert · unset.

counter-increment

counter-increment: <name> <integer> | none

Each box shows the counter value after three successive increments.

none — no increment (values stay 0)

myCounter — increment by 1

myCounter 1 — increment by 1

myCounter 2 — increment by 2

myCounter -1 — decrement by 1

myCounter 0.5 — increment by 0.5

myCounter anotherCounter — increment multiple

Global keywords also apply: inherit · initial (none) · revert · unset.

counters()

content: counters(<name>, <separator>) | counters(<name>, <separator>, <list-style-type>)

Each nested list joins every level's value with its separator.

    1. mid
      1. leaf
