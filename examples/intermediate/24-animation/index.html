Animation

animation

animation: <name> <duration> <timing> <delay> <iteration> <direction> <fill-mode> <play-state>

fade

fadeIn 1s ease-in-out — name and duration

multi

fadeIn 1s ease-in-out, slideUp 0.5s ease — multiple animations

full

pulse 1s ease-in-out 0.2s infinite alternate both — full shorthand

Global keywords also apply: inherit · initial (none 0s ease 0s 1 normal none running) · revert · unset.

animation-name

animation-name: none | <keyframe-name>

none

none — no animation

fadeIn

fadeIn — run the fadeIn keyframes

slideUp

slideUp — run the slideUp keyframes

both

fadeIn, pulse — multiple animations

Global keywords also apply: inherit · initial (none) · revert · unset.

animation-duration

animation-duration: <time>

0s

0s — no animation

0.5s

0.5s — half a second

1s

1s — one second

2000ms

2000ms — milliseconds

1s, 0.5s

1s, 0.5s — multiple durations

Global keywords also apply: inherit · initial (0s) · revert · unset.

animation-timing-function

animation-timing-function: ease | linear | ease-in | ease-out | ease-in-out | cubic-bezier() | steps()

Compare how each easing curve drives the slide.

ease

ease — slow start and end

linear

linear — constant speed

ease-in

ease-in — accelerates

ease-out

ease-out — decelerates

ease-in-out

ease-in-out — accelerate and decelerate

bezier

cubic-bezier(0.25, 0.1, 0.25, 1) — custom curve

steps

steps(5, end) — stepped animation

Global keywords also apply: inherit · initial (ease) · revert · unset.

animation-direction

animation-direction: normal | reverse | alternate | alternate-reverse

normal

normal — play forward

reverse

reverse — play backward

alternate

alternate — forward then backward

alt-rev

alternate-reverse — backward then forward

Global keywords also apply: inherit · initial (normal) · revert · unset.

animation-fill-mode

animation-fill-mode: none | forwards | backwards | both

Each box has a 0.5s delay — watch whether start/end styles are held.

none

none — no styles outside the animation

forwards

forwards — keep the end styles

backwards

backwards — apply start styles during the delay

both

both — apply both

Global keywords also apply: inherit · initial (none) · revert · unset.

animation-play-state

running — playing

paused — paused

Two transforms (moveX + moveY) — replace uses one, add/accumulate combine them diagonally.

replace

replace — later animation overrides earlier

add

add — values are added together

accumulate

accumulate — values are accumulated
