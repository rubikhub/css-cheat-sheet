Typography Advanced

font-family

font-family: <family-name> | <generic-family>

serif — Georgia, "Times New Roman", serif.

sans-serif — "Helvetica Neue", Arial, sans-serif.

monospace — Consolas, ui-monospace, monospace.

system-ui — the operating system's default UI font.

Global keywords also apply: inherit · initial · revert · unset.

font-size

font-size: <length> | <percentage> | <absolute-size> | <relative-size>

16px — fixed pixel size

1.2em — relative to parent font size

1.5rem — relative to root font size

120% — percentage of parent

medium — the default size

larger — one step larger than parent

font-weight

font-weight: <number> | normal | bold | bolder | lighter

100 thin

300 light

400 normal (default)

700 bold

900 black

bold keyword

bolder — relative to parent (this parent is 400)

font-style

font-style: normal | italic | oblique <angle>?

normal — upright text (default)

italic — slanted italic text

oblique — synthetically slanted text

oblique 14deg — oblique with angle

font-variation-settings

font-variation-settings: normal | <string> <number>#

Only affects variable fonts — on fixed fonts the values are ignored.

normal — no variation (default)

'wght' 750 — weight axis

'opsz' 36 — optical size axis

'wght' 750, 'opsz' 36 — multiple axes

font-optical-sizing

font-optical-sizing: auto | none

auto — adjust optical size automatically (default)

none — no optical size adjustment

font-synthesis

font-synthesis: none | weight | style | weight style

fake bold fake italic

weight style — allow both (default)

no fake bold no fake italic

none — no fake bold or italic

fake bold no fake italic

weight — bold only

no fake bold fake italic

style — italic only

font (shorthand)

font: <style> <weight> <size>/<line-height> <family>

700 1.2rem/1.4 'Segoe UI', sans-serif — full shorthand

16px sans-serif — size and family

italic bold 1rem Georgia — style, weight, size, family

font-kerning

font-kerning: auto | normal | none

AV To We — auto (default)

AV To We — normal (always kern)

AV To We — none (never kern)

font-stretch

font-stretch: normal | <keyword> | <percentage>

normal — regular width (default)

condensed — narrower face

semi-condensed — slightly narrower

expanded — wider face

semi-expanded — slightly wider

font-stretch: 125%

color

color: <color>

red — named color

#ff5733 — hex color

rgb(255, 0, 0) — RGB color

rgba(255, 0, 0, 0.5) — RGB with alpha

hsl(0, 100%, 50%) — HSL color

transparent — fully transparent

currentColor — matches current text color

word-spacing

word-spacing: normal | <length>

normal — default word spacing

0.5em — half-em extra space between words

-2px — tighten word spacing

vertical-align

vertical-align: baseline | sub | super | top | bottom | middle | <length> | <percentage>

xsuper normal sub middle top bottom 20px

Each span aligns differently against the line box.
