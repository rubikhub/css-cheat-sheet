Image Sizing

aspect-ratio

aspect-ratio: auto | <ratio>

auto

auto — intrinsic ratio (default)

1/1

1 / 1 — square

16/9

16 / 9 — widescreen

3/2

3 / 2 — photo ratio

Width is fixed, height derives from the ratio.

object-fit

object-fit: fill | contain | cover | none | scale-down

Each frame is 140×90 with a 4:3 image squeezed into it.

fill — stretch to fill (default)

contain — fit inside, keep ratio

cover — fill, crop overflow

none — natural size

scale-down — none or contain, smaller

object-position

object-position: <position>

A 160×120 image is cover-cropped into each 140×90 frame — the crop region shows the position.

50% 50% — centered (default)

top — align to top edge

left — align to left edge

right 20px bottom 10px

image-set()

background-image: image-set(<url> <resolution>, ...)

image-set('photo@1x.png' 1x, 'photo@2x.png' 2x)

image-set('photo-640.jpg' 640w, 'photo-1280.jpg' 1280w)

image-set(url(a.avif) type('image/avif'), url(a.jpg))

In this demo the candidates all resolve to the same SVG so it renders everywhere; real usage swaps files by resolution.

object-view-box

object-view-box: inset(<top> <right> <bottom> <left>)

A 160×120 checkerboard is zoomed via the view box.

inset(0) — no crop (default)

inset(25%) — inner 50% square

inset(10% 20% 30% 40%)

image-rendering

image-rendering: auto | crisp-edges | pixelated | smooth

A tiny 4×4 pixel pattern scaled up — compare the scaling algorithm.

auto — quality algorithm (default)

pixelated — nearest-neighbor, hard pixels

crisp-edges — preserve contrast

smooth — always smooth when scaling
