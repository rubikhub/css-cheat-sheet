Transform Functions

translate()

translate(<x>, <y>)

Hover each box to move it from its current position.

xy

translate(100px, 50px) — 100px right, 50px down

x

translate(100px) — moves on the X axis only

X

translateX(100px) — moves horizontally

Y

translateY(50px) — moves vertically

50%

translate(50%, 50%) — percentage-based move

3D

translate3d(100px, 50px, 200px) — 3D move

Z

translateZ(200px) — toward or away from the viewer

rotate()

rotate(<angle>)

Hover each box to rotate it.

45

rotate(45deg) — 45° clockwise

-45

rotate(-45deg) — counter-clockwise

half

rotate(0.5turn) — half turn

rad

rotate(3.14rad) — angle in radians

X

rotateX(45deg) — around the X axis

Y

rotateY(45deg) — around the Y axis

Z

rotateZ(45deg) — around the Z axis

3D

rotate3d(1, 1, 1, 45deg) — around a 3D axis

scale()

scale(<x>, <y>)

Hover each box to resize it.

2×

scale(2) — doubles the size

½

scale(0.5) — halves the size

xy

scale(2, 0.5) — different X and Y factors

X

scaleX(2) — scales horizontally

Y

scaleY(0.5) — scales vertically

backfront

scale3d(1, 1, 2) — 3D scale

backfront

scaleZ(2) — scales along the Z axis

skew()

skew(<x-angle>, <y-angle>)

Hover each box to skew it.

skew

skew(20deg) — skews on the X axis

both

skew(20deg, -10deg) — skews on both axes

X

skewX(20deg) — skews horizontally

Y

skewY(-10deg) — skews vertically

perspective()

perspective(<length>)

Hover each box to apply depth on the element itself.

200px

perspective(200px) rotateY(45deg) — strong depth

500px

perspective(500px) rotateX(30deg) — moderate depth

1000px

perspective(1000px) rotateY(-20deg) translateZ(100px) — combined

Individual transform properties

translate: <length-percentage> ... | rotate: <angle> ... | scale: <number> ...

Hover — each standalone property animates independently of the transform property.

move

translate: 50% 20px — move the element

spin

rotate: 45deg — rotate the element

grow

scale: 1.5 — scale the element

all

translate · rotate · scale — applied in that order
