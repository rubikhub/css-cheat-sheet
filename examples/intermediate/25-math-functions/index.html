Math Functions

calc()

calc(<expression>)

Each bar below is sized by a real calc() — the label shows the formula and the measured result on this page.

calc(100% - 40px) — full row minus a fixed 40px → ≈ 880px

calc(100vh - 80px) — viewport height minus 80px → window-dependent

calc(1rem + 10px) — rem plus px → 16px + 10px = 26px

calc(2 * 1rem) — multiply a value → 2 × 16px = 32px

calc(14px + 0.5vw) — fixed plus viewport unit → ≈ 19px at a 1000px window

calc(50% - 100px) — offset a percentage → ≈ 460px - 100px = 360px

calc(100% - calc(2 * 20px)) — nested calculation → ≈ 880px

min()

min(<values>)

min(50%, 300px) — 50% ≈ 460px would exceed 300px → width = 300px (capped)

min(100vh, 600px) — viewport-based size capped at 600px → 600px on tall windows

Aa

min(2vw, 16px) — font-size capped: 2vw ≈ 20px → 16px

pad

min(2rem, 40px) — padding: 2rem = 32px is the smaller → 32px

min(90%, 800px) — fluid width capped at 800px → 800px

m

min(5%, 50px) — margin-left: 5% ≈ 46px is smaller → ≈ 46px

max()

max(<values>)

max(50%, 300px) — 50% ≈ 460px is the larger → width = 460px

max(100vh, 600px) — takes 100vh whenever the window is taller than 600px

Aa

max(1rem, 16px) — font-size floor → 16px (equal, no change)

pad

max(2rem, 40px) — padding floor: 2rem = 32px < 40px → 40px

max(80%, 600px) — 80% ≈ 736px is the larger → 736px

m

max(5%, 50px) — margin floor: 5% ≈ 46px < 50px → 50px

clamp()

clamp(<min>, <preferred>, <max>)

Aa

clamp(12px, 2vw, 16px) — fluid font: 2vw ≈ 20px → clamped to 16px

clamp(300px, 50%, 800px) — preferred 50% ≈ 460px → 460px

pad

clamp(0.5rem, 2vw, 2rem) — padding → 2vw ≈ 20px

m

clamp(1rem, 3vw, 3rem) — margin → 3vw ≈ 30px

clamp(200px, 50vh, 600px) — 50vh within bounds → ≈ half the window height

clamp(0.5rem, 1vw, 1rem) — flex gap → ≈ 10px between the squares

env()

env(<custom-ident>, <fallback>)

The safe-area insets exist and are 0px in desktop browsers, so the phones show no padding here — on a notched phone they report the real inset. The last cell uses an undefined env() name so you can see the fallback kick in.

top

env(safe-area-inset-top) — 0px on desktop

bottom

env(safe-area-inset-bottom) — 0px here; the real bottom inset on phones

left

env(safe-area-inset-left, 0px) — 0px on desktop

right

env(safe-area-inset-right, 12px) — 0px here (real inset wins over fallback)

fallback

env(--demo-inset, 16px) — undefined env() var → fallback 16px is used
