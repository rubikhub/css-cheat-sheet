Logic Matching Selectors

:is()

:is(<selector-list>)

Each heading and card below matches the list — hover a card.

is(h1, h2, h3)

:is(h1, h2, h3) — any heading level 1–3

:is(.card, .panel)

:is(.card, .panel):hover

:is(.card, .panel)

:is(.card, .panel):hover

Specificity equals the most specific argument. Also inherits the usual keywords: inherit · initial · revert · unset.

:where()

:where(<selector-list>)

where(h1, h2, h3)

:where(h1, h2, h3) — any heading, zero specificity

:where(.card, .panel)

:where(.card, .panel):hover

overridden

:where() has zero specificity, so a plain rule overrides it

Matches like :is() but never adds specificity — easy to override.

:not()

:not(<selector-list>)

All chips are styled, except disabled ones and the last chip.

one disabled three four
a div

:not(input) matches non-inputs

disabled

:not(.disabled) — excluded

Chained negatives work too: :not(.active):not(.disabled).

:has()

:has(<selector-list>)

Cards that contain an image get highlighted. Check the box to light up the form.

.card:has(img) — has image

text only

.card:has(img) — no match

Also matches focused groups (.group:has(input:focus)) and hovered navs (nav:has(a:hover)).
