CSS Nesting

& <selector> | &:pseudo-class | @media <condition>

Group descendant, state, and media rules inside their parent. The source below is the actual nested CSS in this page's style.css.

.nestcard {
  padding: 14px;
  border: 1px solid #e2e8f0;

  & .title { font-weight: 700; }

  & a { color: #3b82f6; }

  &:hover { border-color: #3b82f6; }

  &.active { background: #eff6ff; }

  & a.external::after { content: " ↗"; }

  @media (max-width: 768px) {
    padding: 8px;
  }
}
