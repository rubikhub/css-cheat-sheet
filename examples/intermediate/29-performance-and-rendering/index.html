Transform vs Layout Animation

animation with transform / opacity vs top / left / margin

Both boxes slide the same distance. The transform box animates on the compositor; the left box forces layout on every frame.

transform: translateX() — compositor-only, smooth

left — triggers layout each frame, more jank

translate vs top/left

translate: <length> vs top / left

Same visual movement, different cost: the translate property is composited and doesn't reflow siblings.

translate: 120px — composited, no layout

left: 120px — layout-triggering
