Transition Advanced

transition

transition: <property> <duration> <timing> <delay>

Hover each box to watch its transition.

single

color 0.3s ease — transition a single property

multi

color 0.3s ease, background 0.5s ease-in-out — multiple properties

all

all 0.3s ease — transition all properties

Global keywords also apply: inherit · initial (all 0s ease 0s) · revert · unset.

transition-property

transition-property: <property> | none | all

Hover — only the listed property animates; anything else changes instantly.

color

color — transition color changes

bg

background-color — transition background changes

fade

opacity — transition opacity changes

move

transform — transition transforms

shadow

box-shadow — transition shadow changes

multi

color, background-color, opacity — transition multiple properties

all

all — transition all properties

none

none — transition nothing

Global keywords also apply: inherit · initial (all) · revert · unset.

transition-duration

transition-duration: <time>

Hover — longer durations animate more slowly.

0s

0s — no transition (default)

0.3s

0.3s — quick transition

500ms

500ms — half-second transition

1s

1s — one-second transition

2.5s

2.5s — slow transition

two

0.3s, 0.5s — per-property durations

Global keywords also apply: inherit · initial (0s) · revert · unset.

transition-timing-function

transition-timing-function: <timing-function>

Hover — compare how each curve accelerates the same slide.

ease

ease — slow start and end (default)

linear

linear — constant speed

ease-in

ease-in — slow start, fast end

ease-out

ease-out — fast start, slow end

ease-in-out

ease-in-out — slow start and end

bezier

cubic-bezier(0.25, 0.1, 0.25, 1) — custom curve

bounce

cubic-bezier(0.68, -0.55, 0.27, 1.55) — bounce curve

steps

steps(5, end) — jump in discrete steps

start

step-start — jump to end instantly

end

step-end — hold until the end

Global keywords also apply: inherit · initial (ease) · revert · unset.

transition-delay

transition-delay: <time>

Hover and hold — the transition waits before it starts.

0s

0s — start immediately (default)

0.2s

0.2s — short delay

500ms

500ms — half-second delay

1s

1s — one-second delay

two

0s, 0.2s — per-property delays

Global keywords also apply: inherit · initial (0s) · revert · unset.

linear() easing

transition-timing-function: linear(<points>)

Hover — piecewise-linear easing built from stop points.

ramp

linear(0, 0.5, 1) — a three-point ramp

stops

linear(0, 0.3 20%, 0.9 80%, 1) — stops with positions

transition-behavior

transition-behavior: normal | allow-discrete

Hover the box — a hidden label appears; allow-discrete fades it in, normal pops it.

normalpop

normal — no discrete property transitions (default)

fadepop

allow-discrete — allows transitions of discrete properties
