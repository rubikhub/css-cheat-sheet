shape-image-threshold

shape-image-threshold: <number>

The float image is a soft-edged gradient circle (inline SVG). Raising the threshold shrinks the wrap toward the fully-opaque core.

Threshold — only pixels above the alpha threshold shape the wrap. A soft edge lets low thresholds wrap broadly while high thresholds keep the text near the center.

0.0 — any opaque pixel counts (default)
