Attribute Selectors

[attr] — presence

[attr]

title attribute

[title] — any element with a title

data-tag

[data-tag] — any data attribute

Global keywords also apply: inherit · initial · revert · unset.

[attr~="value"] — word in a list

[attr~="value"]

Each chip has a class token list — only chips containing the matching word light up.

highlight

[class~="highlight"] matches

active

[class~="active"] matches

primary

[class~="primary"] matches

muted

[class~="muted"] — no rule

Matches only a whole word in a space-separated list — not a substring.

[attr|="value"] — value or value- prefix

[attr|="value"]

hreflang="en"

[hreflang|="en"] matches

hreflang="en-US"

en-US also matches (hyphenated)

hreflang="fr"

[hreflang|="fr"] matches

hreflang="zh-CN"

[data-lang|="zh"] matches via data-lang

Matches exact value or value followed by a hyphen (language + region).

[attr^="value"] — starts with

[attr^="value"]

https://example.com

[href^="https"] matches

http://example.com

[href^="http"] matches

user-42

[data-id^="user-"] matches

admin-1

[data-id^="user-"] no match

Useful for secure links, prefixes, and grouped ids.

[attr$="value"] — ends with

[attr$="value"]

manual.pdf

[href$=".pdf"] matches

archive.zip

[href$=".zip"] matches

photo.jpg

[data-file$=".jpg"] matches

photo.png

[data-file$=".png"] matches

Useful for styling links and assets by file type.

[attr*="value"] — contains substring

[attr*="value"]

example.com

[href*="example"] matches

btn-primary

[class*="btn"] matches

avatar-small

[src*="avatar"] matches

menu-item

[data-name*="admin"] no match

Matches the substring anywhere in the attribute value.
