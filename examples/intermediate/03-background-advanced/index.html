Background Advanced

background-image

background-image: <image> | <gradient> | none

none — no image (default)

linear-gradient(to right, red, blue)

linear-gradient(135deg, #667eea 0%, #764ba2 100%)

radial-gradient(circle, red, blue)

conic-gradient(red, orange, yellow, green, blue)

Global keywords also apply: inherit · initial (none) · revert · unset.

repeating-linear-gradient()

background: repeating-linear-gradient(<angle>, <color-stops>)

90deg — stripes every 40px

45deg — diagonal stripes

repeating-radial-gradient()

background: repeating-radial-gradient(<shape>, <color-stops>)

circle — concentric rings

background-repeat

background-repeat: repeat | repeat-x | repeat-y | no-repeat | space | round

repeat — tile both ways (default)

repeat-x — horizontal only

repeat-y — vertical only

no-repeat — single image

space — even spacing

round — tile and scale

Two-value forms also work, e.g. repeat space, no-repeat space, repeat round.

background-position

background-position: <position> | <x> <y>

A small dot is positioned inside each frame.

center (default)

top

bottom

left

right

20px 40px — x/y offsets

top right — keyword pair

right 10px bottom 20px

background-attachment

background-attachment: scroll | fixed | local

scroll — background scrolls with the page. Resize or scroll the window to compare.

scroll (default)

fixed — background stays pinned to the viewport.

fixed

local — background scrolls with the element content. Scroll inside this box!

local

Two-value form also works, e.g. local scroll.

background-clip

background-clip: border-box | padding-box | content-box | text

Each box has a dashed border and padding — the colored area shows the paint boundary.

border-box

border-box — extends under border (default)

padding-box

padding-box — stops at padding edge

content-box

content-box — stops at content edge

gradient text

text — clipped to the glyphs

background-origin

background-origin: border-box | padding-box | content-box

padding-box

padding-box — origin (default)

border-box

border-box — starts under border

content-box

content-box — starts inside padding
