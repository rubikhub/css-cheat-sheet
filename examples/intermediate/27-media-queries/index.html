Media Features

@media (<feature>: <value>)

width / min-width / max-width — the grid reflows at 600px

h

height / min-height — box grows above 700px-tall windows

orientation — box is wide (landscape) or tall (portrait)

aspect-ratio — e.g. 16/9

resolution — device pixel density, e.g. 2dppx

Range Syntax

@media (min-width <= width <= max-width)

Modern range syntax without min-/max- prefixes. The gauges read the window width, not the card — resize the browser.

(400px <= width <= 700px) — between 400 and 700px

(width >= 600px) — same as min-width: 600px

(width < 1000px) — narrower than 1000px

(600px < width) — wider than 600px

Logical Operators

@media <condition> and <condition> | @media or | not <condition>

and — all conditions must match (wide AND landscape)

or — any condition can match

not — negates the whole query

, — comma list acts like or

Interaction Features

@media (hover: none) | (pointer: coarse)

Hover me

hover — can the primary input hover? Card lifts only when (hover: hover)

any-hover — can any input hover?

pointer — accuracy of the primary pointer: fine / coarse / none

any-pointer — accuracy of any pointer

User Preference Queries

@media (prefers-color-scheme: light | dark)

These reflect your OS settings — toggle dark mode / reduced motion in your system preferences to see them change.

Light or dark?

prefers-color-scheme — the card restyles itself

bounce

prefers-reduced-motion — the box stops bouncing when reduce is set

prefers-contrast — no-preference | more | less

prefers-reduced-transparency — no-preference | reduce

Display & Device Features

@media (color-gamut: srgb | p3 | rec2020)

Read-only gauges reporting your current display capabilities.

color-gamut — display color range

dynamic-range — standard | high (HDR)

update — none | slow | fast refresh

scripting — JS availability
