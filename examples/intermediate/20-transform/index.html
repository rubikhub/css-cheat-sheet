Transform

transform

transform: <transform-list> | none

Hover each box to apply its transform.

none

none — no transform (default); hover straightens the tilt

rotate

rotate(45deg) — rotates the element

scale

scale(2) — resizes the element

skew

skew(20deg) — skews the element

move

translate(100px, 50px) — moves the element

3D

perspective(500px) rotateX(45deg) — 3D rotation with perspective

combo

rotate(45deg) scale(1.5) — multiple transforms combined

Global keywords also apply: inherit · initial (none) · revert · unset.

transform-origin

transform-origin: <position>

Hover — the same 35° rotation pivots around each origin.

center

center — center of the element (default)

top left

top left — top-left corner

bottom right

bottom right — bottom-right corner

offset

100px 50px — fixed offset point

50% 50%

50% 50% — percentage point

3D

50% 50% 100px — 3D origin with z-offset

Global keywords also apply: inherit · initial (50% 50% 0) · revert · unset.

transform-box

transform-box: content-box | border-box | fill-box | stroke-box | view-box

SVG only — picks the reference box for transform-origin; hover rotates each rect from its top-left.

content-box — content box as reference

border-box — border box as reference (default)

fill-box — object bounding box as reference

stroke-box — stroke bounding box as reference

view-box — nearest SVG viewport as reference

Global keywords also apply: inherit · initial (border-box) · revert · unset.

perspective

perspective: none | <length>

Hover — shorter lengths give stronger depth on the same rotateX(45°).

X

none — no perspective (default)

X

200px — strong perspective

X

500px — moderate perspective

X

1000px — subtle perspective

Global keywords also apply: inherit · initial (none) · revert · unset.

perspective-origin

perspective-origin: <position>

Hover — the vanishing point shifts while the card rotates in 3D.

Y

50% 50% — center vanishing point (default)

Y

0 0 — top-left vanishing point

Y

100% 100% — bottom-right vanishing point

Y

center top — keyword position

Y

200px 100px — fixed offset position

Global keywords also apply: inherit · initial (50% 50%) · revert · unset.

backface-visibility

backface-visibility: visible | hidden

Hover — both flip 180°; visible shows the mirrored back, hidden goes blank.

back

visible — back face shown (default)

back

hidden — back face hidden

Global keywords also apply: inherit · initial (visible) · revert · unset.
