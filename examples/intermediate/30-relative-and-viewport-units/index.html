Relative & Viewport Units

ex — X-Height

font-size: 0.75ex · vertical-align

ex is the height of a lowercase "x" — roughly half the font size, used for baseline-aligned details.

x sub 0.75ex

subscript at 0.75ex — sits at the x-height

ch — Character Width

max-width: 65ch · width: 20ch

ch is the width of the "0" glyph. Resize the window — the paragraph stops at 65 characters per line.

A readable measure uses around 65 characters per line — ch makes the column adapt to whatever font is used. This box is max-width: 65ch.

max-width: 65ch — ideal reading width

input width: 20ch — fits ~20 characters

lh — Line Height

max-height: 3lh · overflow: hidden

Line-clamp style truncation with pure CSS — exactly three lines, no matter the font size.

This paragraph is limited to three lines using max-height: 3lh. Any overflow is hidden, so the visible text always ends at a clean line boundary regardless of font size.

max-height: 3lh — always shows exactly 3 lines

vmin / vmax — Viewport Min / Max

width: 40vmin · height: 40vmin

A square sized with vmin always fits both portrait and landscape — it tracks the shorter viewport side. Resize the window.

40vmin

width & height: 40vmin — square that fits any orientation

svh / lvh / dvh — Mobile Viewport Heights

height: 100dvh · height: 100svh

On mobile, the URL bar changes the visible height. dvh tracks it live; svh always uses the smallest height. On desktop they are equal.

100dvh

100dvh — dynamic: follows the URL bar

100svh

100svh — small: never taller than the compact viewport
