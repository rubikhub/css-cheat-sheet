:visited

Visit a link (then come back) — :visited needs a real browser-history visit and cannot be forced. Visited links turn purple.

.link:visited — custom visited links

:focus-visible

Use Tab to focus via keyboard — the ring appears only for keyboard (not mouse) focus.

button:focus-visible — buttons when keyboard focused

input:focus-visible — inputs when keyboard focused

a:focus-visible — links when keyboard focused
